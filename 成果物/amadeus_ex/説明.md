# アマデウス紅莉栖 モーション追加の成果物

Live2Dモデル「amadeus_ex」に、既存のパラメータだけで作った新規モーションを7種類追加した記録です。
モデル本体(moc3・テクスチャ・物理演算設定・表示情報・編集用ファイル)は、ライセンス上ここには含めていません。

## 追加したモーション

| 分類 | 表示名 | ファイル | 長さ | 表現 |
|---|---|---|---|---|
| 感情 | 微笑み | kurisu_smile.motion3.json | 3.0秒 | 目を閉じた笑い目(^^)、口角、ほんのり頬の赤み |
| 感情 | 照れ隠し | kurisu_embarrassed.motion3.json | 4.5秒 | 頬を真っ赤にして目をそらし、への字口で、前で手を組んでもじもじ |
| リアクション | びっくり | kurisu_surprised.motion3.json | 2.5秒 | 一瞬のまばたきから目を丸く見開き、口を開ける |
| リアクション | ジト目 | kurisu_jitome.motion3.json | 4.0秒 | 半目で視線をそらし、横目でちらっと戻す(呆れ顔) |
| 待機 | きょろきょろ | kurisu_lookaround.motion3.json | 4.0秒 | 左・右・上と視線を送る。途中でまばたき |
| 待機 | うとうと | kurisu_sleepy.motion3.json | 5.0秒 | まぶたが重くなり、あくびをして、はっと目を覚ます |
| 仕草 | 考え中 | kurisu_thinking.motion3.json | 4.5秒 | あごに手を当て、むっとした考え顔で視線は斜め上 |

すべて繰り返しなしの単発再生で、最初と最後は待機姿勢(初期値)に戻ります。

## フォルダの中身

```
motion/                    追加した7つのモーションファイル
amadeus_ex.py              モーション定義(リポジトリの motion-defs/ に置くもの)
設定ファイル/
  amadeus_ex.model3.json   モーションを登録済みのモデル設定(元の設定に Action グループを足しただけ)
  model.config.json        WebUIが読み込むモデルの場所
スクリーンショット/
  実際のWebUI/             各モーションを再生し、長さの25%・50%・75%の時点で固定して撮影したもの
  一覧/                    上記の顔部分の一覧、手元の拡大など
  パラメータ調査/          各パラメータを最小・最大にしたときの見え方(設計の根拠)
説明.md                    このファイル
```

## 元に戻す手順(新しい環境で)

1. このリポジトリを取得し、モデル一式(moc3を含むフォルダ)を用意する
2. `python3 tools/setup_model.py <モデルのフォルダ>` でモデルを配置する
3. `amadeus_ex.py` を `motion-defs/amadeus_ex.py` に置く(リポジトリにも登録済み)
4. `python3 tools/gen_motions.py` でモーションを生成・登録する
   (ここの `motion/` と `設定ファイル/amadeus_ex.model3.json` を、直接 `models/amadeus_ex/` へ上書きコピーしても同じ結果になります)
5. `python3 tools/validate_motions.py` で「OK」が出ることを確認する
6. `python3 -m http.server 8765` を起動し、ブラウザで http://localhost:8765 を開く
7. 右側の「今回追加したモーション」の★ボタンで7つを個別に再生できる

## このモデルの特徴と設計上の判断

- 頭・体の角度、眉のパラメータが存在しない。首振りやうなずきは作れないため、目・視線・口・頬・考える腕だけで表現した
- 目の開閉は1つのパラメータで両目が同時に動く。ウィンクは作れない
- 笑い目パラメータは「目の開き0」と組み合わせると(^^)、「目の開き1」と組み合わせると目が丸く見開かれる。後者を「びっくり」に使った
- 口は最大でも小さくしか開かないため、しゃべる動きは表現が弱い。当初案の「解説モード」は外した
- 考える腕のパラメータは、1.9で両手を前で組む姿勢、4以上であごに手を当てる姿勢になる。3.4付近は腕が宙に浮く途中形なので、そこで止めないようにした
- 物理演算で動くパラメータ(まつ毛・瞳・腕と髪の揺れ・腕の追従)と呼吸は直接動かしていない
- モーション再生中は自動まばたきが止まるため、長めのモーションにはまばたきを入れた

## 検証結果

- `tools/validate_motions.py`:合格(終了コード0)
- 既存モーションがないため、同スクリプトの値域・基本姿勢チェックは省略される。代わりにモデル本体の最小値・最大値・初期値で全カーブを確認し、合格
- 実際のWebUIをブラウザで再生して撮影し、7つすべてで狙った表情・姿勢になっていること、破綻や不自然な透けがないことを目視で確認
